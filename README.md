Project Overview
An interactive Excel dashboard designed to track and analyze Superstore sales, profitability, and regional performance.

Key Objectives

Visualize key metrics such as Total Sales, Total Profit, and Top Region.

Analyze sales trends over time and identify top-performing sub-categories.

Enable dynamic data filtering using interactive Slicers for Categories, Regions, and Segments.

Tools Used

Microsoft Excel 2016

Power Query (Data Cleaning)

PivotTables & PivotCharts

Interactive Dashboard Design
